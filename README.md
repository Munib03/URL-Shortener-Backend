# URL Shortener Backend

A backend API for creating short, shareable URLs from long links, built with **Node.js, Express.js, PostgreSQL, Prisma, and Zod**.

## Tech Stack

- **Node.js**
- **Express.js**
- **PostgreSQL**
- **Prisma ORM**
- **Zod**

## Features

- User registration
- Email validation with Zod
- Duplicate email prevention
- Password handling
- PostgreSQL database integration
- Prisma ORM and database management
- Database migrations
- URL shortening
- Short URL redirection
